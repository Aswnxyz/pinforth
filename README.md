# Pinforth

A planned collaborative product for website feedback, issue tracking, fix verification and client approval.

## Problem

Website feedback often gets scattered across messages and screenshots. Pinforth aims to keep an issue, the discussion around its fix, and the client's approval in one workflow.

## Planned capabilities

- Capture feedback in the context of a website or page.
- Track issues, ownership and status with collaborators.
- Record fix verification and client approval.
- Explore AI assistance for organizing feedback and supporting review.

These are product intentions, not implemented features.

## Status

Planning stage. As of 18 October 2026, this repository contains documentation only; there is no runnable application, demo or test suite.

## Provisional technical direction

A TypeScript full-stack monorepo is proposed. Framework, database, authentication, deployment and AI provider choices remain open and should follow an agreed first-use case. No application scaffold or installation commands are included until implementation begins.

The first useful milestone is a small end-to-end workflow: capture feedback, resolve it, verify the fix and record approval. Collaborator responsibilities and acceptance criteria should be agreed before expanding scope.
